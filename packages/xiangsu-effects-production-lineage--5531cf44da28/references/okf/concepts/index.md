# Concepts

- [绿美型特效定义](001-绿美型特效定义.md) - 由滤镜、美妆、美型三部分组成的特效，分别作用于色彩效果、妆容叠加和面部形变
- [2D贴纸特效定义](002-2d贴纸特效定义.md) - 使用2D图像或动画素材组合创意搭配，增强拍摄氛围、装饰面部或呈现风格的特效
- [视觉元素标注规则](003-视觉元素标注规则.md) - 绿字表示拉开距离，蓝字表示偏移角度
- [碰撞检测基础](004-碰撞检测基础.md) - 用于判断两个物体是否接触或相交的物理交互基础
- [眨眼翻转角度作用](005-眨眼翻转角度作用.md) - 设定睫毛在眨眼时的动态翻转角度；课程示例当前值为30°，不代表统一默认值，实际制作需根据预览调整。
- [三维坐标系与空间定位](006-三维坐标系与空间定位.md) - 视频中多次显示三维坐标（x:0.00, y:0.00, z:0.00），且在后期出现具体坐标值（如x:89.07, y:-68.69, z:32.46），说明教学内容涉及空间坐标系统的设定、理解与应用。
- [UI/UX 优化](007-ui-ux-优化.md) - 插件的界面设计与交互优化
- [软件界面功能模块认知](008-软件界面功能模块认知.md) - 界面顶部菜单栏包含基础功能项，工具栏图标对应多种功能模块
- [对象面板结构与操作](009-对象面板结构与操作.md) - 左侧对象面板提供搜索功能和展开项，用于查找素材或管理特效
- [核心节点构成](010-核心节点构成.md) - 模板由规则/AI节点和2D渲染节点组成
- [节点链式连接结构](011-节点链式连接结构.md) - 通过连线构建节点逻辑流实现复杂特效
- [向量角度的概念](012-向量角度的概念.md) - 视频引入“向量角度”作为核心概念，用于描述向量在平面坐标系中的方向。
- [角度0度的定义](013-角度0度的定义.md) - 向量角度为0时，表示向量沿水平轴正方向延伸，即指向正右方（x轴正方向）。
- [坐标系方向基准](014-坐标系方向基准.md) - 默认以水平向右为0度基准方向，符合标准数学直角坐标系中角度测量的起始规则（从正x轴逆时针旋转）。
- [3D物体与2D前景贴纸的渲染等价性](015-3d物体与2d前景贴纸的渲染等价性.md) - 绿色方块3D物体在渲染层级和显示逻辑上与2D前景贴纸一致，始终位于其他物体前方不被遮挡
- [事件触发设置](016-事件触发设置.md) - 存在"同时满足触发"开关和"重复触发"选项设置
- [文字组件的渲染特性](017-文字组件的渲染特性.md) - 文字组件在渲染组中不受任何底层3D物体遮挡，但会被2D前景遮挡。
- [落子图效果](018-落子图效果.md) - 这是一个X轴运动，点击屏幕Y轴方向向下落子图
- [连接锚点概念](019-连接锚点概念.md) - 连接锚点表示被链接物体上的连接位置，是相对于物体本身的坐标。
- [组件ID标识系统](020-组件id标识系统.md) - 通过为组件分配唯一ID实现对象独立控制，解决多实例管理问题。
- [自定义节点基础结构](021-自定义节点基础结构.md) - 演示了自定义节点脚本的基本TypeScript结构，包含类定义、装饰器和输入输出声明
- [触发条件类型](022-触发条件类型.md) - 触发条件包括人脸检测、表情检测、五官检测、手势检测等
- [排行榜基础参数](023-排行榜基础参数.md) - 抽样面板中可见排行榜类型为“个人”、优先展示为“全国排行”、最小分数0、最大分数1000、单位为“分”、排序为“从高到低”。这些是示例当前值，不能认定为统一默认或平台限制；具体团队类型选项需回原视频核对。
