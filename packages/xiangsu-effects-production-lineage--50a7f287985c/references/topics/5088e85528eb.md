# 物理关节

物理关节主题涉及在3D编辑器中设置和调整关节参数以实现物体间的物理连接和运动效果。

## 设置旋转关节

在属性面板中设置旋转关节的锚点和轴参数以控制旋转方向。

1. 选择需要设置旋转关节的物体
2. 在属性面板中找到"旋转关节"部分
3. 设置"锚点"参数（如"-5, -5, 0"）
4. 调整"轴"参数（如"0, 0, 1"表示Z轴）
