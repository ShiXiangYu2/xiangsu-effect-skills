# Workflows

- [LUT滤镜制作流程](001-lut滤镜制作流程.md) - 使用PS模板制作并导出带滤镜信息的色卡
- [脸部拉伸形变操作](002-脸部拉伸形变操作.md) - 通过编辑蓝色点位调整面部轮廓
- [球体弹跳优化流程](003-球体弹跳优化流程.md) - 通过添加碰撞体和调整物理参数改善弹跳效果
- [实时预览工作流](004-实时预览工作流.md) - 左侧参数调整与右侧预览窗口实时联动
- [数据流控制实现](005-数据流控制实现.md) - 多节点连接实现数据处理流水线
- [生成残局棋谱流程](006-生成残局棋谱流程.md) - 使用配套编辑器创建自定义残局数据
- [变量计算逻辑构建](007-变量计算逻辑构建.md) - 通过“变量计算”功能对指定变量进行数值处理，包括选择计算类型、数值和目标变量。
- [虚拟形象头饰添加完整流程](008-虚拟形象头饰添加完整流程.md) - 完整展示从基础角色状态到添加头饰并实时预览的全过程。
- [添加2D画笔节点](009-添加2d画笔节点.md) - 通过弹出的“添加组件”对话框，添加了名为“2D 画笔”的功能，该功能包含子项“画笔”、“清空画布”、“抬起”、“按下”。
- [设置画笔参数](010-设置画笔参数.md) - 在“2D 画笔”节点中，输入参数“最小大小”被设置为10.00，“最大大小”被设置为2.00。
- [连接2D线段碰撞体](011-连接2d线段碰撞体.md) - 语音解释了需要在节点中连接“2D 画笔”与“2D 画线”。
- [面部涂鸦玩法实现流程](012-面部涂鸦玩法实现流程.md) - 通过渲染纹理和3D面具实现面部涂鸦，需调整材质颜色和节点连接
- [位移动画基础设置](013-位移动画基础设置.md) - 设置2D位移节点的运动类型为位移，起点坐标为0，终点坐标为200，运动时长为2.0
- [节点连接步骤](014-节点连接步骤.md) - 输入端无需连接，输出端连接三次同一个需要移动物体的位置复值
- [节点系统搭建](015-节点系统搭建.md) - 展示完整节点结构 —— 从输入（点击事件）到运动控制（位移节点）再到输出（对象状态）
- [继承数据基本流程](016-继承数据基本流程.md) - 特效加载后从云端拉取继承数据，延迟1秒检查是否存在数据。若无数据走新建流程，若有数据需提示用户选择新建或继承。
- [新建/继承选择流程](017-新建-继承选择流程.md) - 获取数据成功后显示两个选项按钮：1.新建继承（清空数据从0开始） 2.直接开拍（继承他人数据）。
- [多组件同步控制](018-多组件同步控制.md) - 通过自定义组件实现多个方块同步运动，需创建组件并绑定变量控制。
- [数组数据处理流程](019-数组数据处理流程.md) - 通过循环节点（数值设为100）获取数组数量，合并字符串后显示排名与分数，需清空文本避免累积
