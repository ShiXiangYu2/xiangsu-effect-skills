# 换壳案例库（三次真实任务）

沉淀自三次模板换壳，作为 `reskin-playbook.md` 的对照实例。每个案例给出：模板、主题、路径、关键参数、踩坑。

## 案例一：《兔兔甜品师》（模板 e583290d，instance_id=1）

- **类型**：韩系甜妹萌系 **跟脸贴纸**模板换壳（贴纸类 → AI 生图路径）
- **资产**（AI 生图后绑定到多个跟踪槽）：
  - `r75` BunnyEarsHat → 5 个跟头贴纸槽（c107/c111/c115/c119/c123）
  - `r77` GoldGlassesV2 → 5 个镜框槽（c65/c73/c81/c89/c97）
  - `r76` BunnyWhiskerBlushV2 → 5 个胡子槽（c67/c75/c83/c91/c99）
  - `r73` BunnyChefMascot → s71 角落吉祥物
  - 鼻子 `r16` 动态纹理保留
- **踩坑**：V1（r72/r74）眼镜过淡、兔须过长上扬遮眼 → 重生成 V2（r77 焦糖金粗框、r76 短须不上扬）重绑通过；V1 冗余已删。

## 案例二：《蜜桃乌龙妆》（模板 921b410e，instance_id=1）

- **类型**：伪素颜 → 韩国学妹 **AI 妆容变身**（UV 面部贴图 → PIL 调色路径）
- **原纹理位置**：`Assets/temp.folder/`（eye.png / blusher.png / lips0000.png）
- **调色函数**：`recolor(src,dst,rot_base,rot_full,sat_mul,val_add)`——按饱和度加权旋转色相
- **绑定**：
  - eye_peach → c24（s12）
  - blusher_peach → c18（s10）
  - lips_oolong → c30（s14），tint 重置白色 (1,1,1,1)
  - 美瞳 c15（s9）EyeColorV2 color → (0.62, 0.42, 0.18) 蜜棕
- **踩坑**：唇色偏黄（中位 46°）→ 重调 +35° 转橘棕（中位 29.7°，RGB 234/189/145），降饱和 28%。

## 案例三：《草莓奶昔蕉》（模板 d6de8f00，instance_id=1）

- **类型**：韩系甜妹 + **3D 香蕉头套**模板换色（模型贴图 → PNG 覆盖 + re-import）
- **香蕉皮贴图**（两份都要改）：`Assets/香蕉/纹理/香蕉_1_color.png` 与 `Assets/香蕉 (1)/纹理/`
- **阈值校正**（来自 `--analyze` 实测，58° 为分界）：
  - 黄皮 48–60° → 草莓粉 (345°, 饱和×0.42, 亮+0.14)
  - 蒂 60–78° → 薄荷绿 (155°)
  - 棕柄 30–42° → **保留**（keep）
- **球体贴图**：`球体_1_color_2.png` 奶黄 → 奶油白粉 (348°, 饱和×0.3, 亮+0.18)；深棕蒂 → 草莓粉
- **绑定**：唇 `r14` → lips_strawberry 绑 s11；眼 `r22` → eye_strawberry 绑 **c26**（s13 对象 GUID 解析失败，改用组件 GUID c26）
- **踩坑**：首版阈值误用 <90° 分支，把"绿蒂"(实测 58–78° 黄绿)整片转粉 → 从备份恢复，按实测 58° 重调。
