参数是这些案例的测量值，不是所有设备/发型/像塑版本的默认值。脚本样例是经历史编译和预览验证的案例快照；移植前核对当前 API、节点前提、坐标及资源绑定。不要将其直接加载进不匹配的工程。

## 验证边界

月亮猫：编辑器正脸/摇头和编译通过；没有手机实拍或活动提交证据。
剃光头：实际点击确认、取消、恢复、重复流程通过；后来用户报告宿主拍摄按钮遮挡，修复后编辑器点击通过，手机复核未完成。静音 MP4 不能证明音效可听。
蜘蛛：模型导入、原版转头和无人脸、循环版完整一圈及接缝抽帧通过；逐足 IK、逐发丝遮挡、移动端性能和连续出入镜未验证。
