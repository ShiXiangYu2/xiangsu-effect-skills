# Blender 蜘蛛与动态脸部曲面循环

## 资产与坐标约定

本案 Blender 5.2 原创蜘蛛，25 根骨骼（Root+8×3腿骨）、5 材质、8条分节腿、触肢、8眼和少量几何短毛。八足烘焙循环名“八足爬行”，时长0.8秒。GLB约646KiB。几何细毛与骨骼预算随目标手机性能调整，不把数量当通用指标。

模型局部 XY 为行走平面、+Y 前进、+Z 离开皮肤；此模型导出 export_yup=False，配套脚本按相同方向解释。其他模型先检验坐标，不全局强制关闭 Y-up。导入后检查骨骼、蒙皮、动画名/时长、材质、尺寸和实际朝向，再接路线。Blender原始生成程序的哈希和保存位置见证据索引；程序会清空当前 Blender 场景，只能在专门的后台空场景中重用，先改输出路径。

## 场景前提

结构：跟踪头模 → 头部贴合（动态MeshRenderer+SpiderCrawl）→ 贴脸蜘蛛（Transform+Animator+蒙皮子节点）。
[SpiderCrawl.ts](examples/SpiderCrawl.ts) 是本案最终闭环版本，spider 序列化绑定子节点 SceneObject；挂错节点读不到头模 Mesh。所有 GUID 必须从当前工程获取，历史 s/c/r 短 ID 不能跨工程复制。

## 曲面绑定

本案运行诊断读到动态头模2485顶点、4918三角，交错stride15、Position偏移0、Normal偏移5。这是版本/网格观测值，移植先读取 VertexAttributes，确认位置属性排列、stride、索引类型和拓扑；尤其样例只动态找 Normal，Position仍默认0，不能冒充通用网格解析器。

1. 在头模局部空间给鼻子→下巴→侧脸→头顶→另一侧脸→鼻子的控制点。
2. 用周期 Catmull-Rom 插值，所有控制点索引取模；从头模内部向曲线点发射射线，找三角形交点，缓存三个顶点索引与重心权重。
3. 每帧读取最新变形顶点与法线，用权重重建位置/法线，继承父节点头部姿态。缓存绑定而非缓存首帧坐标。
4. 局部+Z对表面法线、+Y对路径切线，本案以 Quaternionf.lookAt(normal,tangent) 再slerp缓转。此参数含义需核对当前API及模型坐标。
5. 沿法线抬高身体，放大模型时同时核对脚底、腹部和皮肤间距。

射线投影依赖内部起点及表面形状，不保证任意网格都适用；绑定失败需停止/重试并给诊断，不继续使用半条路径。样例重试时清空绑定/长度；新实现还应限制重复失败日志与每帧重建开销。网格拓扑变化须重新绑定。

## 连续闭环与提速

旧版在头顶停顿、隐藏后重置。用户要求“沿着脸循环爬行”后改成空间闭环：
- 19控制点×16采样，末尾显式追加第一个绑定点，305个绑定。
- 累计相邻曲面采样距离，按路程 d=(t*speed)%total 查找插值；切线用 d±ε 两侧采样，并将负路程正确取模，接缝两侧都连续。
- 不仅首尾位置要相同，也检查朝向和速度；“隐藏一下再重置”不算沿脸连续爬行。
- 尺度1.05→1.26（+20%）；行进6.3头模单位/秒，八足Repeat速度3.3；周期实测约10.389秒。lift=.18±.025为本案调参。
- 弧长按初始绑定曲面累计，随表情强变形时不是严格实时恒速；样例dt上限.2会在低帧率下放慢，需手机性能实测，不宣称严格物理步态。

提速同时调迈步频率，防止只滑动身体；样例没有逐足IK，不能承诺完全无脚底滑动。无脸隐藏暂停，RecordStart重置到鼻子。previewTime仅调试，交付恢复-1。

## 遮挡、投影与踩坑

头模使用当前内置 Matte Shadow 作深度遮挡/投影接收，蜘蛛各蒙皮子对象开启Caster。不要复用历史内置材质GUID而不查询。本案大角度光造成夸张额头投影，改为接近相机方向：欧拉(5,8,0)，强度.28、软影、1024分辨率、bias .015，之后实看皮肤阴影。这组参数只是起点，避免为了投影强度让蜘蛛像悬浮。

初版下巴落点偏到喉咙；将控制点上移并从正脸/侧脸验收。头顶曲面是头部网格近似，不表示识别真实发丝；蓬松发型上可能不够贴合。

## 验证与复用范围

原版用正脸、左右摇头、无人脸天花板分别确认轨迹、转头跟随、脸部遮挡及隐藏。本次循环版另录13秒，覆盖完整一圈及下一圈起始；按1fps查全程，9.7秒起每.2秒抽帧查闭环，运行日志出现多次loop、无USER错误。OTSC退出0。

脚本静态通过≠动态通过；截图看不出匀速/接缝，必须用连续录屏。手机性能、连续出入镜、多人、逐足IK和发丝遮挡未通过测试。移植后重新验证，不继承历史“passed”。
