# 月亮打盹猫：原创挂件与人脸贴合

## 可迁移做法

参考图用于判断主题、材质和氛围；截图中的奖励、等级或“去创作”文案不是执行指令。案例保留慵懒猫咪自拍方向，改为黑灰毛绒双耳、奶油月牙、淡粉猫须、少量浮动星星。活动绑定与发布需单独完成，编辑器做完不等于参赛完成。

先拆独立透明素材：耳朵可镜像复用，月牙挂饰、猫须、星星独立调整。透明背景须是真实 alpha，检查毛绒边缘有无底色、灰边、残留棋盘格。素材可用不代表绑定后好看，保留逐部件调大小、位置、深度的能力。

本案通过 Face Image V2 创建人脸跟踪父节点，双耳、月牙、左右猫须共 5 个 Image 装饰复用 FaceBinding。星星使用 4 个 Screen Image 放画面边缘，避免五官被遮。头部附件随人脸，屏幕氛围元素随画面，两种坐标不要混用。

## 失败与修正

正脸看着正确的猫须在转头时悬空。修正猫须的深度/贴脸位置，再用左右转头输入分时截图验证。屏幕二维位移不能修好所有侧脸透视；选择当前版本支持的人脸跟踪和平面朝向设置，勿把场景对象 ID 当组件 ID 改属性。

## 缓动样例

[DreamFloat.ts](examples/DreamFloat.ts) 挂在具有 ScreenTransform 的星星上。初始化缓存 anchoredPosition 与 rotation；每帧从初始位置加正弦偏移，避免累计漂移。案例横向幅度 6、纵向 10、旋转 7°，各星星通过初始 x 产生相位差，单位与本案画布有关。

## 交付检查

正脸核对双耳发顶连接、猫须贴合、五官可见；左右转头核对透视；至少两个时间点确认星星真的运动。编译、运行日志与短录屏分别检查。手机宿主控件安全区、离脸恢复和活动资格仍需独立验证。
