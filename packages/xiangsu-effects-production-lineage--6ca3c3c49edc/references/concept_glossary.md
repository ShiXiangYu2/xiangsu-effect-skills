# 像塑课程概念

- **绿美型特效定义**：由滤镜、美妆、美型三部分组成的特效，分别作用于色彩效果、妆容叠加和面部形变（证据：evidence_d42c39a914037c590c649075）
- **2D贴纸特效定义**：使用2D图像或动画素材组合创意搭配，增强拍摄氛围、装饰面部或呈现风格的特效（证据：evidence_903938dfbd79e03d53c7d3a2）
- **视觉元素标注规则**：绿字表示拉开距离，蓝字表示偏移角度（证据：evidence_7c22616dbbbecc4a451516cb）
- **碰撞检测基础**：用于判断两个物体是否接触或相交的物理交互基础（证据：evidence_930c5e33fae175101321c905）
- **眨眼翻转角度作用**：设定睫毛在眨眼时的动态翻转角度（默认30°），用于提升动画自然度。（证据：evidence_171f4adaec953a7e7117314c）
- **三维坐标系与空间定位**：视频中多次显示三维坐标（x:0.00, y:0.00, z:0.00），且在后期出现具体坐标值（如x:89.07, y:-68.69, z:32.46），说明教学内容涉及空间坐标系统的设定、理解与应用。（证据：evidence_aca18bc6a0f8f7539d670d89）
- **UI/UX 优化**：插件的界面设计与交互优化（证据：evidence_4c02df7dabe63c9a16366fe6）
- **软件界面功能模块认知**：界面顶部菜单栏包含基础功能项，工具栏图标对应多种功能模块（证据：evidence_f2cf53e8d26a6d51988fc992）
- **对象面板结构与操作**：左侧对象面板提供搜索功能和展开项，用于查找素材或管理特效（证据：evidence_e8b698d02cb944671616728a）
- **核心节点构成**：模板由规则/AI节点和2D渲染节点组成（证据：evidence_079166f56b7a1ecbc403c7b3）
- **节点链式连接结构**：通过连线构建节点逻辑流实现复杂特效（证据：evidence_be977362a6c25cb91497c0cb）
- **向量角度的概念**：视频引入“向量角度”作为核心概念，用于描述向量在平面坐标系中的方向。（证据：evidence_b2767caf9cc97ff25fb64a86）
- **角度0度的定义**：向量角度为0时，表示向量沿水平轴正方向延伸，即指向正右方（x轴正方向）。（证据：evidence_b2767caf9cc97ff25fb64a86）
- **坐标系方向基准**：默认以水平向右为0度基准方向，符合标准数学直角坐标系中角度测量的起始规则（从正x轴逆时针旋转）。（证据：evidence_b2767caf9cc97ff25fb64a86）
- **3D物体与2D前景贴纸的渲染等价性**：绿色方块3D物体在渲染层级和显示逻辑上与2D前景贴纸一致，始终位于其他物体前方不被遮挡（证据：evidence_13e980a8f880d4cb9fce23e0）
- **事件触发设置**：存在"同时满足触发"开关和"重复触发"选项设置（证据：evidence_364fac76c92065239c8c56b2）
- **文字组件的渲染特性**：文字组件在渲染组中不受任何底层3D物体遮挡，但会被2D前景遮挡。（证据：evidence_8127362fd861b2a5e6ac5239）
- **落子图效果**：这是一个X轴运动，点击屏幕Y轴方向向下落子图（证据：evidence_d033a19bfbd7b8ee21ccd0b0）
- **连接锚点概念**：连接锚点表示被链接物体上的连接位置，是相对于物体本身的坐标。（证据：evidence_5e6b7a734087b78144103a5a）
- **组件ID标识系统**：通过为组件分配唯一ID实现对象独立控制，解决多实例管理问题。（证据：evidence_90d8883ae35db9b6d834892e）
- **自定义节点基础结构**：演示了自定义节点脚本的基本TypeScript结构，包含类定义、装饰器和输入输出声明（证据：evidence_e3b99951302aaf7a0b0bb7e5）
- **触发条件类型**：触发条件包括人脸检测、表情检测、五官检测、手势检测等（证据：evidence_c910d70e29287b9bb2249c96）
- **排行榜基础参数**：抽样面板中可见排行榜类型为“个人”、优先展示为“全国排行”、最小分数0、最大分数1000、单位为“分”、排序为“从高到低”。这些是示例当前值，不能认定为统一默认或平台限制；具体团队类型选项需回原视频核对。（证据：evidence_a45d23a08eeaa2043e76b656）
