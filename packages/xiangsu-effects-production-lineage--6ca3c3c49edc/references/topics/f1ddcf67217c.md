# 推箱子

推箱子特效制作教学

## 使用推箱子关卡编辑器

通过浏览器访问推箱子关卡编辑器，推荐从模板创建关卡，内置100多个模板可供选择。

1. 在浏览器中输入关卡编辑器网址
2. 选择从模板创建关卡
3. 选择一个简单模板进行观察

## 编辑关卡工具介绍

关卡编辑器提供五个工具：放置玩家、放置箱子、放置目标、放置墙体和擦除内容。

1. 使用第一个工具放置玩家到不同位置
2. 使用第二个工具放置箱子
3. 使用第三个工具放置目标
4. 使用第四个工具放置墙体
5. 使用第五个工具擦除不必要内容

## 测试和导出关卡

编辑完成后可以试玩关卡进行测试，测试成功后可导出关卡数据。

1. 点击试玩关卡进行测试
2. 使用WASD控制玩家上下左右移动
3. 点击游戏复位恢复到初始状态
4. 测试成功后返回编辑
5. 点击导出关卡获取关卡数据

## 在像素探索板中使用关卡数据

将导出的关卡数据粘贴到像素探索板的指定位置，完成特效制作。

1. 全选并复制关卡数据
2. 进入像素探索板找到粘贴位置
3. 删除原有内容后粘贴新关卡数据
4. 点击空白处预览新关卡
5. 开始录制测试关卡
6. 无问题后发布特效
