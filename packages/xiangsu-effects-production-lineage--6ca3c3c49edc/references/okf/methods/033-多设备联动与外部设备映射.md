# 多设备联动与外部设备映射

在11分00秒后，左侧出现摄像头实时画面（工业设备、蓝色灯光），说明教学涉及外部传感器或摄像头输入，并将其与虚拟节点系统联动，实现“真实世界—虚拟系统”实时交互。
