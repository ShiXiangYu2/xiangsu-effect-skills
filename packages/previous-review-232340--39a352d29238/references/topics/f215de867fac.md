# Blender Link插件

Blender Link插件用于在Blender和像素软件之间进行模型和材质的联动。

## Blender Link插件安装路径

插件需要解压后放置到Blender的特定目录中。

1. 解压插件包，包含插件文件夹和配送库。
2. 将配送库放置到Blender安装目录的python\lib文件夹中。
3. 将插件文件夹放置到用户文件夹的AppData\Roaming\Blender Foundation\Blender\4.2\scripts\addons中。
4. 在Blender偏好设置中启用插件并保存用户设置。

## Blender Link插件使用

插件可以导入像素的头模、面具等参考模型。

1. 打开像素软件并新建项目，确保插件显示已联通。
2. 在插件中选择导入标准的像素头模、面具或包头面具。
3. 将Blender中的模型缩小、移动并平滑着色。
4. 通过插件导入模型到像素工程中，添加3D跟踪。

## 更新导入的模型

可以在Blender中修改模型后更新到像素工程中。

1. 在Blender中对模型进行修改，如添加细分修改器。
2. 在插件中选择更新，将修改后的模型同步到像素工程中。
3. 注意选中的物体会被更新，未选中则更新整个场景。

2. 通过插件将模型和材质导入到像素工程中。
3. 在像素软件中查看导入的材质效果。
