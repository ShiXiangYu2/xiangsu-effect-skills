# 继承数据

继承数据节点用于实现社交属性的特效玩法，如成语接龙、默契度挑战等，通过获取和设置继承记忆数据实现用户间的数据传递。

## 继承数据基本流程

特效加载后从云端拉取继承数据，延迟1秒检查是否存在数据。若无数据走新建流程，若有数据需提示用户选择新建或继承。

1. 加载特效时从云端获取继承数据
2. 延迟1秒检查数据是否存在
3. 无数据时执行新建数据流程
4. 有数据时提示用户选择操作
