# 模型与资产来源玩法指南

## 能力指引

先判断模型在玩法中承担的作用，再决定绑定方式和来源。
以下分组是判断视角，不是互斥路由；
脸部、身体、手部和足部模型仍应先回到对应区域的玩法指南。

### 模型在玩法中的作用

- **二维贴附或区域效果**：贴纸、粒子、描边、换色和分割遮罩通常不需要导入模型，
  先读对应的身体、脸部、手部、足部或分割指南。
- **刚性模型挂件**：帽子、耳饰、背包、简单道具和几何装饰只需要模型和绑定点，
  不要升级为全身模型。
- **局部表面模型**：模型需要贴合脸、手、脚或身体表面时，先确认目标区域的跟踪
  或网格绑定能力，再决定使用 `PinToMesh`、局部 Tracker 或专用对象。
- **全身替身**：需要完整身体替换、骨骼驱动、姿态重定向或多关节联动时，
  才进入 `FullBodyAvatar` 路线。模型必须具备可用骨骼和蒙皮。

### 模型来源与准备

3D 模型来源按以下优先级检查：当前工程已有且匹配度足够高的模型、
Prefab 和内置 3D 模型优先级最高；外部工具或 Skill 不存在时，不要临时硬找。

1. 当前工程已有且匹配度足够高的模型、Prefab 和内置 3D 模型。
2. 已有的外部建模或生成工具及对应 Skill，例如已配置的 Blender；
   完成后再走模型导入和结构检查。
3. 用户提供的本地模型文件，走模型导入和结构检查。
4. 没有合适资产且需求能用简单几何表达时，才自建简易模型。

如果用户明确指定已有资产、内置资产或模型来源，
按用户指定来源执行，不套用默认优先级。

候选模型只需先确认用途匹配，以及目标区域所需的绑定点、骨骼或网格结构；
搜索结果不能证明这些条件已经满足，需通过预览或导入后的工程结构确认。
具体格式、尺寸、材质、骨骼和导入验证统一读取 `ModelImport` Skill。

`ModelImport` 只负责模型来源和导入，不提供跟踪、分割、绑定或骨骼驱动能力；
这些能力由目标区域的专用对象或组件负责。
