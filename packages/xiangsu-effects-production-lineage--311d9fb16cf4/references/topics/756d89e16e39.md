# 好友头像

实现好友头像的随机选择和视觉优化

## 随机头像选择机制

通过节点系统实现从多个头像中随机抽取一个显示

适用条件：需要实现随机头像选择功能

1. 添加好友头像并编号
2. 创建数组并包含所有好友头像
3. 使用'随机'节点生成索引
4. 从数组中获取对应索引的头像并显示

依据：好友头像::visual；原始视频 `D:\workbuddy\像塑特效\学习素材\好友头像 - 像塑工具文档 - 像塑桌面版 外部文档空间.mp4`。类型：课程证据整理；置信度中，术语与界面待核对。

支持片段：通过节点系统实现从多个头像中随机抽取一个显示

## 好友不足时的处理

当好友数量不足时使用小动物头像补充

适用条件：好友数量少于需要的随机选项数量

依据：好友头像::speech；原始视频 `D:\workbuddy\像塑特效\学习素材\好友头像 - 像塑工具文档 - 像塑桌面版 外部文档空间.mp4`。类型：课程证据整理；置信度中，术语与界面待核对。
