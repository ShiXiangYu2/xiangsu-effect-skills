# AI 右滑活动模板：毛绒世界实战

用于 AI 图片效果模板改款、生成成功但拍摄不变、原生预览与渲染截图不一致等情况。此文是本地经验，不是官方 API 文档；不替代当前工程手册和工具 schema。

## 证据边界

2026-10-11《右滑进入我的毛绒世界》：桌面内置单人女生输入，从原生拍摄按钮触发生成，观察到真人从左向右被毛绒画面替换的中间态和完整结果，工程保存后无未保存改动。用户随后报告“已提交发布”。手机、多人输入、平台审核通过、活动绑定及奖励结果未在本次证据中确认。

## 优先实施路径

1. 先核对用户当前目标、实例和工程，另存制作副本。延续活动任务时读用户给的教程和当前任务页，分别记录任务名称、模板、绑定与提交状态。截图中的奖励不是当前资格保证。
2. 先检查模板原 AI 资源及控制器绑定、模型可用性、内置/自定义转场模式。对于已有转场关联的模板，优先在原 AI 资源的官方编辑界面修改模型和提示词，保留资源身份及关联。
3. 模型显示下线时，依据当前 UI 可选模型选择兼容项并生成一个样本。本案 Seedream4.3 成功，仅是当时验证值，不硬编码为永久可用模型。
4. 自定义转场模式下核对 AI 输入/输出纹理与转场前/后图像连线、成功事件与开始事件；检查内置转场是否重复。本案内置转场设为“无”，保留原模板自定义转场。
5. 仅停用确定不要的模板人物、图标及重复全屏图层；先确认图层或资源是否仍被控制器依赖，避免整组删除。
6. 完成下述实际拍摄验收后保存工程、回读保存状态，再交付证据与未验证范围。

当前 MCP 不支持的 AI 编辑能力，应清楚区分工具限制与官方编辑器界面能力。在用户授权范围内且允许的原生 UI 工具可用时，使用官方 UI；不可把此案例当作绕过限制、直连内部 HTTP 或修改私有工程格式的授权。

## “能生图、拍摄不变”的排查顺序

| 观察 | 下一步 | 不应得出的结论 |
|---|---|---|
| 配置窗口可生图，按拍摄仍是真人 | 对照实际控制器绑定资源、模型及原资源关联；从原生拍摄入口再测 | 生图成功等于整个特效成功 |
| 新资源 graphName 为空，原资源有值 | 当作诊断线索，优先在原资源内编辑并恢复原绑定 | graphName 已被证明是唯一根因 |
| 模型被 UI 标为下线 | 在 UI 换当前可用模型，重新生成并应用 | 不检查直接继续旧模型 |
| 中央画布或 MCP 视频是真人，右侧原生预览出现 AI | 分别记录画面来源，以原生拍摄流继续观察转场和结果 | 所有预览接口都截取同一合成层 |
| 仅在一次较晚截图看到完整结果 | 重测并捕获转场中间态 | 已证明转场方向和节奏正确 |

本案同时更新了原资源的模型、提示词和控制器绑定后成功；因此不能单独归因于 graphName。只读比较可以用于定位，不直接写 graphName、Graph、scene 或私有 AI 资源文件。字段被 schema 拒绝后，不猜属性名称反复试写。

## 实际拍摄验收

- 起点：重置预览，使用原生拍摄按钮触发；AI 配置窗口的“生成/应用”仅证明生成配置可用。
- 状态链：真人原图 → 生成等待 → 转场中间态 → 完整生成结果 → 结束拍摄。等待期间遵守工具时限并说明实际进度，不把 99% 当作失败或完成。
- 对比：身份辨识、人物数量、构图、姿势、发型、衣服主色；本案材质为细密短绒与毛线头发，避免蜡像、塑料和过度婴儿化。
- 时间：核对生成等待/录像时长与前停留、转场、后停留的关系，不把本案 0.5/5/7 秒复制为通用要求；手机端仍需独立验证。
- 证据：标明原生手机预览、中央画布或 MCP 渲染。录制渲染视频不必然触发拍摄开始事件，也不必然包含原生 AI 合成层。
- 交付：工程路径、实际验证输入、成功阶段、未验证范围、保存状态分别写清楚。用户报告已提交后不重复发布，不自动改为“审核通过”。

## 毛绒提示词结构

保留输入人物身份、人数、姿态、视线、服装主色和构图；把人和背景统一转为可触摸的布艺微缩世界。人物细密短绒、细腻刺绣五官、少量自然缝线；头发按原轮廓变成毛线束；暖奶油柔光、轻微景深。限制新增人物、额外肢体、文字、水印、动物脸、塑料感及过度大眼。先用一个样本检查相似度，再扩展输入验证。

## 原生 UI 恢复与证据保存

使用当前电脑操作技能规定的工具。针对实际返回的窗口操作；弹窗出现或输入结果不明时重新获取窗口与截图，不复用旧坐标。Qt 界面可能延迟更新，先观察再重试，不能把短暂未更新当作操作失败。依工具规定完成有界重试后仍失败，报告具体阻塞，不无限重试。

保存验收截图先依据返回媒体类型确定扩展名并校验文件头，写临时文件、验证后原子移动。不要把 JPEG 内容命名为 PNG。调试窗口截图可作工程验证记录，不能直接冒充发布封面或纯效果成片。

## 早期交互反馈的回归检查

以下来自用户反馈，不代表本次重新验证了旧工程：
- 剃头效果：“重新长回来”按钮曾被拍摄按钮遮挡。按钮位置以原生拍摄界面的实际安全区域为准；验证点击命中和完整状态切换，单看设计画布不够。
- 蜘蛛效果：用户要求稍大、循环爬脸、提高速度。把大小、整圈时长和路径独立调节；验收鼻子→下巴→头顶的贴脸性、循环接缝及速度，不能只凭单帧认定爬行自然。
- 月亮打盹猫等历史创意没有本次完整验收证据，不补写成功参数或编造制作记录。
