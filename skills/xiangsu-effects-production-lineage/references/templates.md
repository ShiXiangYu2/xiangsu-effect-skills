# 像塑制作任务模板

以下为本包的实施整理模板，不是教师原话。

- 效果目标与一次完整使用流程：
- 课程主题及证据编号：
- 素材：文件、格式、尺寸/时长来源、透明背景、版权或用户授权、项目内位置。
- 场景/组件：父子关系、跟踪锚点、渲染层级。
- 事件链：触发条件 → 状态/变量 → 执行动作 → 可见或可听结果。
- 状态表：状态、进入条件、动作、退出条件、重置方法。
- 关键参数：值、来源、允许调整范围；未知项标为待核对。
- 节点/脚本接口：输入、输出、连接、数据类型；无 API 证据时先查源资料。
- 实机验证：动作、预期、实际、证据、异常复现。
- 交付：工程路径、依赖素材、预览路径、未完成项。

- 原创设计：参考/模板保留点、主题/构图/素材/交互/反馈的实质变化、实际相似度检查结果。
- 触发提示对应表：发布提示、画面提示、真实输入动作、条件、预期与实际反馈、重复/重置证据。
- 发布素材：封面授权来源、是否内置模特、与最终工程一致性、不透明底色、裁剪/清晰度/当前尺寸校验。
- 验证层级：工程保存、编译、预览、打包、手机、平台检测、审核状态分别记录。
