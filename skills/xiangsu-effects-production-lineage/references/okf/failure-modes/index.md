# Failure Modes

- [棋盘参数不匹配错误](001-棋盘参数不匹配错误.md) - 修改棋盘属性后未同步节点参数导致显示异常
- [渲染顺序错误导致的遮挡异常](002-渲染顺序错误导致的遮挡异常.md) - 未正确设置渲染顺序时，关键UI元素可能被意外遮挡
- [默认材质导致融合失败](003-默认材质导致融合失败.md) - 未启用遮罩时模型无法显示用户面部图像
- [随机数字与针数不同步](004-随机数字与针数不同步.md) - “随机数字”节点的值为9.632，但“2D动画属性”节点的“针数”输入框显示为0.00，未同步更新。
- [自动开拍重置问题](005-自动开拍重置问题.md) - 启用自动开拍重置会导致继承数据变量被清空，必须使用手动配置开拍触发才能保留数据。
