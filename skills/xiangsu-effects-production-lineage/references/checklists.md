# 像塑交付检查

本清单为实施推断，用于核验实际工程，不代表课程中的统一审核规则。

- 工程能够打开，素材和脚本依赖可解析。
- 每条事件链能用实际动作触发，并产生预期效果。
- 重复触发、停止触发、重新开始后状态正确，不残留上次计数或对象。
- 跟踪效果在正面、转头、靠近/远离及遮挡后恢复；记录实际失败条件。
- 2D/3D层级、透明边缘、遮罩、纹理和音效同步符合设计。
- 用户指定设备上的预览与编辑器一致；尚未实机测的项目明确标注。
- 性能或上传参数引用实际工具检查结果；无证据时不写固定包体/帧率阈值。
- 交付包含工程、素材依赖与预览证据，未知术语和平台规则另列待核对。

## 发布与审核反馈专项

准备发布或处理退回时，执行 [审核和发布前检查](review-preflight.md)：分别核对原创性、名称主题、非内置模特封面、清晰裁剪与底色、真实交互提示、打包/手机效果。未具备的证据记为待补，不能用调试预览替代发布封面。
